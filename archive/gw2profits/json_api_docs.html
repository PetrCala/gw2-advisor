Optional Arguments:
  • pretty_print - outputs as JSON_PRETTY_PRINT which is easier for humans to read
    • Example: http://gw2profits.com/json/v3?pretty_print=yes
  • ids - returns recipes with those recipe id's, separated by commas
    • Example: http://gw2profits.com/json/v3?ids=-111,-112
  • output_ids - returns the recipes that make those item id's, separated by commas
    • Example: http://gw2profits.com/json/v3?output_ids=19699,19698
  • names - returns the recipes that make items with those names, separated by commas
    • Example: http://gw2profits.com/json/v3?names=Iron Ore,Gold Ore
  • nameslike - returns the recipes that make items with whos names contain these, separated by commas
    • Example: http://gw2profits.com/json/v3?nameslike=Ore,Log
  • disciplines - returns only the recipes with these disicplines
    • Example: http://gw2profits.com/json/v3?disciplines=Mystic Forge

  • these can also be combined to refine/expand your search
    • AND = search for both arguments
    • OR = search for either argument
    • , = 'OR' for multiple of the same argument
    • AND has precidence over OR, OR is implied: 1,2 AND 3 OR 4 = (1 OR 2) AND (3 OR 4)
    • Examples:
      http://gw2profits.com/json/v3?output_ids=19698&names=Orichalcum Ore,Mithril Ore  (output = 19698 OR name = Orichalcum Ore OR name = Mithril Ore)
      http://gw2profits.com/json/v3?types=GreatswordANDdisciplines=Mystic Forge  (type = Greatsword AND discipline = Mystic Forge)
      http://gw2profits.com/json/v3?names=SunriseORtypes=SwordANDdisciplines=Mystic Forge  ((name = Sunrise OR type = Sword) AND discipline = Mystic Forge)
